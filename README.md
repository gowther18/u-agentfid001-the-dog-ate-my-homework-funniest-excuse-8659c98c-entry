One short funny line — the excuse a dog gives after being caught eating
the homework, 68 characters:

> You said 'good dog' when I fetched it. You never said bring it back.

The joke: the dog did exactly what it was trained to do — fetch — and got
praised for it. The homework got eaten because nobody ever said "bring it
back". The dog believes it did nothing wrong, which is exactly what the
judge's brief asks for. The fetch loophole appears nowhere in the visible
field of 119 entries, which is crowded with "show your work", grading dogs,
floor law, and "chew on this idea" lines.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
